# Academia Metamorfose — Centro de Treinamento

Landing page oficial de alta conversão e pré-matrícula da **Academia Metamorfose**.

## 🚀 Tecnologias
- **HTML5** Semântico
- **Vanilla CSS3** (Design System Dark Atlético, Efeitos Glow & Animação Ken Burns GPU)
- **JavaScript ES6+** (Contador Regressivo, Validação de Formulário, Máscara e Integração WhatsApp)
- **Vite** para empacotamento rápido

## 📦 Como rodar localmente
```bash
npm install
npm run dev
```

## 🛠️ Build de Produção
```bash
npm run build
npm run preview
```

## 🌐 Deploy na Vercel
Pronto para deploy automático com detecção do Vite.
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
